لمعة AI — نموذج أولي مجاني ## ماذا يعمل الآن؟ - واجهة عربية RTL متجاوبة للهاتف والكمبيوتر. - إدخال سكريبت وتقسيمه إلى مشاهد مع توقيت تقريبي. - إنشاء برومبت أولي لكل مشهد وتعديله ونسخه. - تنزيل خطة المشاهد بصيغة JSON. - تجربة صوت عربي عبر Speech Synthesis الموجود في المتصفح، إذا كان مدعومًا على الجهاز. ## ما الذي لا يعمل بعد؟ هذا نموذج واجهة أمامية فقط. لا يولّد ملفات فيديو AI فعلية ولا يضمن صوتًا مصريًا طبيعيًا. لتوليد فيديو حقيقي يجب ربطه بخدمة توليد فيديو/صوت عبر backend آمن؛ لا تضع مفاتيح API السرية داخل index.html. ## نشر مجاني باستخدام GitHub Pages 1. سجّل الدخول إلى https://github.com وأنشئ مستودعًا جديدًا باسم `lumaa-ai` (Public). 2. ارفع `index.html` إلى جذر المستودع. 3. افتح Settings → Pages. 4. ضمن Build and deployment اختر Deploy from a branch، ثم `main` و`/ (root)`، واضغط Save. 5. انتظر اكتمال النشر؛ سيظهر رابط الموقع في صفحة Pages. يمكن أيضًا رفع `index.html` إلى خدمة استضافة static مجانية مثل Cloudflare Pages أو Netlify Drop، حسب شروط الخطة المجانية المتاحة. ## الخطوة التالية لتوليد فيديو فعلي نحتاج اختيار مزود نموذج فيديو وصوت، والتحقق من حدوده المجانية. تُحفظ مفاتيح API على خادم/وظيفة serverless وليس داخل المتصفح. النموذج الحالي لا يرسل بيانات المستخدم إلى خادم.
